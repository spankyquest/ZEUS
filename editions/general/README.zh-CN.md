# ZEUS — Zero Effort Utility Spamming（一键上Buff）

**作者 SpankyQuest · 0.5.4 · 魔兽世界：无限（World of Warcraft: Forever）**

**强化你的盟友，粉碎你的敌人。**

练级路上顺手给路人上Buff，是法系职业能做的最暖心的事之一，也是最繁琐的事之一。ZEUS把它变成了一个按键。按下你的Buff按键（或滚动鼠标滚轮、连点宏），ZEUS就会找到附近下一位缺少你Buff的玩家，选中他并施放。一直按下去，它就会把周围的人挨个上完。

ZEUS用于脱战上Buff：在主城、在飞行点、在队伍集合时。战斗中它什么也不做，脱战后自动继续。

这是游戏允许范围内最接近"自动上Buff"的方式。暴雪不允许插件自行施法，所以每个Buff仍需要你按一下。其余的事ZEUS全包了：选目标、挑选合适的法术等级、记住谁已经有了Buff。所有能上Buff的职业都可以用：法师、牧师、德鲁伊、圣骑士、术士和萨满祭司。

## 功能

- **自动选目标。** 你的目标最先，然后是你周围的玩家：默认低等级优先，你设置的职业顺序用于区分同等级的玩家（也可以改成职业顺序优先）。每个Buff只给需要它的职业：奥术智慧给法系职业，力量祝福给战士和潜行者，以此类推。
- **合适的等级。** 低等级玩家会得到他们能接受的法术等级，身上同类Buff等级较低的玩家会得到升级。在"高级"里你可以让ZEUS施放较低的等级来节省法力；在训练师那里学会新等级后会自动切换过去。
- **一次上齐。** 一位玩家会先拿到你勾选的所有Buff，ZEUS才会换下一个人。
- **快到能给飞行中的人上Buff。** ZEUS会在你按键前准备好下一个Buff，速度快到坐飞行坐骑从你头顶经过的玩家也很容易上到，只要他们进入施法距离。
- **按时补Buff。** Buff剩多少时补上，由你决定。
- **不会卡住。** 被墙挡住的玩家会排在视线内所有人之后。如果游戏提示已有更强大的法术在起作用，ZEUS会找出是哪个Buff挡住了，在它消失前不再理会那位玩家。
- **远离PvP麻烦。** 你未开启PvP时，会跳过已开启PvP的玩家。
- **Buff时长。** `/zeus report` 统计你一共给出了多少Buff时间。
- **看看谁给了你Buff。** 鼠标指向你身上的Buff即可看到施放者，左键点击可以密语对方道谢。
- **回Buff。** 鼠标指向你身上的某个Buff，再按Buff按键或Buff宏：如果施放者需要你的Buff并且在距离内，ZEUS就会给他回一个。鼠标移开后几秒内依然有效，方便你去点动作条上的宏。
- **你的语言。** English、Deutsch、Español、Français、Português (Brasil) 和简体中文。

圣骑士每位玩家只给一个祝福，按职业选择：战士和潜行者给力量，法系职业给智慧，猎人、德鲁伊、萨满祭司和其他圣骑士给王者。不同圣骑士的祝福可以叠加，所以如果别人已经给了这个祝福，ZEUS会换下一个。你自己给出的祝福（手动或用ZEUS）会保留并按时刷新。

## 快速上手

1. 用新手盒子、CurseForge或Wago安装ZEUS；或者从 [Releases](https://github.com/spankyquest/ZEUS/releases) 页面下载 `ZEUS-0.5.4.zip`（不要点绿色的 **Code** 按钮），解压到游戏的 `Interface/AddOns` 文件夹，确保最后是 `Interface/AddOns/ZEUS/ZEUS.toc`。
2. 进入游戏，输入 `/zeus`。
3. 点击 **选择按键...**，然后按下你想用的按键，或点击鼠标按键、滚动滚轮。（也可以把 **Buff** 图标拖到动作条上。）
4. 点击 **启用ZEUS**。它会打开友方姓名板（游戏默认快捷键 Shift+V，除非你改过），因为ZEUS靠姓名板看到你周围的玩家。
5. 去人多的地方，按下你的按键。

**小提示：** 把Buff绑定到鼠标滚轮，滚一滚就能给整个主城上Buff。ZEUS启用时，反方向滚动不会缩放镜头；禁用ZEUS即可恢复缩放。

**小提示：** ZEUS禁用时Buff宏也能用。连点它，ZEUS会在你点击期间启用（同时打开友方姓名板），停手几秒后再自动禁用。整个过程中你的Buff按键保持原本的功能。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/zeus` | 设置（或左键点击小地图按钮） |
| `/zeus toggle` | 启用或禁用ZEUS（或右键点击小地图按钮） |
| `/zeus report` | 你的Buff时长：总计、今天、每个Buff和等级 |
| `/zeus blockers` | ZEUS学到的会挡住你Buff的效果；`/zeus blockers clear` 清除它们 |
| `/zeus auras` | 你的目标（或你自己）身上的所有Buff，包括法术ID和施放者 |
| `/zeus debug` | 报告问题用的信息 |

## 设置

设置窗口（`/zeus`）会在战斗开始时自动关闭，战斗结束前无法再次打开。

- **Buff：** 勾选你想发放的Buff。
- **职业顺序和等级：** 点击Buff旁边的 **编辑**，然后拖动职业格子（最左边优先），或右键点击某个格子跳过该职业。在"高级"里勾选 **启用低等级Buff** 后，有多个等级的Buff会在格子下方列出所有等级：选择ZEUS要施放的那个（默认是你会的最高等级）。还没学会的等级显示为灰色，并标出训练师从几级开始教授。完成后点击 **锁定**；关闭窗口也会锁定。
- **补Buff滑块：** Buff剩余多少时由ZEUS刷新（默认25%）。设为0%时会等到Buff消失。
- **恢复默认**（右上角，"高级"旁边）：把所有设置恢复到刚安装时的状态，并关闭"高级"。点击两次确认。你的Buff时长会保留。
- **高级**（右上角）会在窗口旁边打开一个抽屉，里面是其他选项。再点一次或关闭窗口即可收起。
  - **按职业排序 / 低等级玩家优先：** 上Buff队列的顺序，决定下一个给谁。默认按等级排列周围的玩家，低等级优先，职业格子只用于区分同等级。勾选 **按职业排序** 让职业格子优先；取消 **低等级玩家优先** 则从最高等级开始。
  - **跳过暂离玩家：** 默认开启。标记为暂离的玩家回来后再上Buff。
  - **跳过1级玩家：** 默认开启，针对停在城里的新小号和仓库号。
  - **立即回Buff：** 默认关闭。其他玩家给你上Buff后，他们会在一分钟内排在队列首位：你下一次按Buff按键或Buff宏就会给他们回一个（需要时ZEUS会先选中他们），前提是他们需要你的Buff。需要开启 **记录谁给了我Buff**。
  - **启用低等级Buff：** 默认关闭。允许你在点击 **编辑** 后，在职业格子下方为Buff选择较低的等级来节省法力。关闭时ZEUS施放你的最高等级。
  - **PvP保护：** 默认开启。关闭时，勾选框下方会提示：给开启PvP的玩家上Buff可能会让你也进入PvP状态。
  - **小地图按钮：** 取消勾选可隐藏按钮；`/zeus` 依然可以打开设置。
  - **记录谁给了我Buff：** 你身上Buff的"施放者"一行，以及左键密语。取消勾选即可同时关闭。游戏只有在能看到施法者时才会告诉你是谁，所以只有打开友方姓名板时才能记下陌生人（ZEUS启用时会自动打开）。记下的施放者在 `/reload` 或重新登录后依然保留，直到Buff结束。回Buff（指向Buff再按键）也需要开启这一项。
  - **防止右键取消Buff：** 默认关闭。开启后，右键点击你的Buff（或武器附魔）不会立即取消：鼠标提示会显示"再次右键确认取消"，5秒内第二次右键才会取消。5秒后恢复正常。战斗中同样有效。
  - **显示队列窗口：** 默认关闭。一个和聊天窗口一样的半透明窗口，从上到下每行列出一位ZEUS接下来要上Buff的玩家：职业图标、等级和职业颜色的名字，字体和大小与你的聊天窗口相同（不在视线内的玩家显示为灰色，排在最后）。拖动可以移动窗口，拖动右下角可以调整大小：窗口越高，显示的名字越多。没有队列时会显示原因（已禁用、没有姓名板、战斗中）。法力不足时，队列依然显示在"法力不足"一行下面。

## Buff时长

`/zeus report` 显示你一共给出了多少小时的Buff。只计算一次施法真正增加的时间：给一个还剩99%的30分钟Buff补一下，只算18秒，不算30分钟。你手动施放的Buff也算，群体Buff按覆盖到的人数分别计算。给自己的Buff不算。数据只保存在你的电脑上，还会按Buff和等级分别统计。详细说明见 [REPORTING.md](REPORTING.md)（英文）。

## 须知

- ZEUS专为《魔兽世界：无限》（World of Warcraft: Forever）制作，不适用于正式服或经典旧世。
- 它从不自动施法，只用于脱战上Buff：战斗中你的Buff按键和宏不会有任何作用。
- 每次登录时ZEUS都是关闭状态。它打开的姓名板会被关回去；你自己打开的姓名板保持不变。
- 开启手柄界面时ZEUS会暂停，切换回鼠标和键盘后恢复。
- 同时装了ZEUS和ZEUS Olympus？只有ZEUS Olympus会运行，并会弹窗提醒你删掉一个。
- 发现问题？请到 [GitHub](https://github.com/spankyquest/ZEUS/issues) 提交，附上你的ZEUS版本、职业、发生了什么、`/zeus debug` 的输出和任何Lua错误。最好用英文提交，用翻译软件也可以。
